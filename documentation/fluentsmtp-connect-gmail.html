Gmail via Other SMTP (App Password Method)

Alternative Setup

Connect Gmail/Workspace using App Passwords

This method uses Google's App Passwords feature to authenticate via FluentSMTP's Other SMTP driver. It bypasses the complex OAuth 2.0 Cloud Console setup process while maintaining secure delivery.

1

Enable 2-Step Verification on Your Google Account

Google requires 2-Step Verification to be enabled on your Google Account before you can generate an App Password.

  • Go to your Google Account Security Settings.
  • Under Signing in to Google, select 2-Step Verification.
  • Follow the on-screen steps to complete the setup if it is not already enabled.
2

Generate a Google App Password

An App Password is a 16-digit passcode that allows FluentSMTP to access your Gmail account securely without sharing your primary password.

  1. Navigate directly to the Google App Passwords Page.
  2. Enter an app name in the text field (e.g., WordPress FluentSMTP).
  3. Click Create.
  4. A pop-up modal will display a 16-character generated password (e.g., abcd efgh ijkl mnop).
  5. Copy this password immediately. Do not close the modal until you have copied it safely.
3

Configure FluentSMTP with "Other SMTP"

Now apply the generated app credentials to your WordPress FluentSMTP plugin settings.

1. Log in to your WordPress Admin Dashboard.

2. Navigate to Settings → FluentSMTP (or click + Add Connection if another provider exists).

3. Select the Other SMTP tab.

Field Name Value / Setting Action
From Email Your full Gmail or Google Workspace email Manual
From Name Your site name or sender name Manual
SMTP Host smtp.gmail.com
Port & Encryption 587 (TLS) OR 465 (SSL)
Authentication Yes (Toggle ON) Enable
SMTP Username Your full Gmail address Manual
SMTP Password 16-character App Password (spaces optional) Paste

4. Click Save Connection Settings.

4

Send a Test Email

Verify that outgoing emails are delivering correctly through the Google SMTP relay.

  1. In FluentSMTP dashboard, click the Email Test tab.
  2. Enter a valid destination email address in the Send To field.
  3. Click Send Test Email.
  4. Check the inbox of the recipient address to confirm success.

Recommended Settings

SMTP Host smtp.gmail.com
Port / Encryption 587 / TLS
Auth Method App Password (16-digit)
Troubleshooting
  • Authentication Error: Ensure 2-Step Verification is active on your Google account.
  • Connection Timeout: Switch between Port 587 (TLS) and Port 465 (SSL) if your host blocks specific outgoing ports.
  • Invalid Password: Copy the 16-character App Password without trailing spaces.
