Connecting Gmail & Google Workspace to FluentSMTP

Configure secure, reliable API-based email routing for your WordPress site. Prevent transactional emails from being flagged as spam or blocked using Google's modern OAuth 2.0 security protocols.

OAuth 2.0 (Recommended)

Secure token authorization. No stored passwords, high deliverability, and full compliance with modern Google security standards.

Basic Password / SMTP

Prone to authentication blocks, frequent password resets, lower delivery confidence, and deprecation risk.

1

Initiate Setup in WordPress

Start by getting your WordPress site's unique redirect URI from FluentSMTP. This tells Google Cloud where to return the authentication credentials after you approve the connection.

  1. Log in to your WordPress Admin Dashboard.
  2. Navigate to Settings → FluentSMTP.
  3. If you already have another provider connected, click Settings in the top navbar and click + Add Connection.
  4. Select the Gmail / Google Workspace tab.
  5. Locate the Authorized Redirect URI field and copy the displayed URL.
Sample Authorized Redirect URI Format WordPress FluentSMTP
https://yourdomain.com/wp-json/fluentsmtp/v1/gmail/callback

Tip: Keep this WordPress tab open in your browser! You will return here in Step 6 to paste the API credentials generated in Google Cloud.

2

Create a Project in Google Cloud Console

Google Cloud Console organizes API access through Projects. Create a designated project for your WordPress email routing.

  1. Open a new browser tab and log into the Google Cloud Console using the exact Gmail or Google Workspace email you want to send emails from.
  2. Click the Project Dropdown near the top left (next to the Google Cloud logo).
  3. In the modal window, click New Project in the top-right corner.
  4. Enter a recognizable Project Name (e.g., WordPress SMTP Mailer).
  5. Click Create and wait a few seconds for the setup to complete.
  6. Ensure your newly created project is selected in the top bar project dropdown.

Important Account Check: Make sure you are logged into the correct Google Account in your browser. If you have multiple Gmail accounts active, verify the account profile icon at the top right of Google Cloud Console.

3

Enable the Gmail API

By default, new Google Cloud projects do not have API access enabled. Enable the official Gmail API service for your project.

  1. In the left sidebar menu, hover over APIs & Services and click Enabled APIs & Services.
  2. Click the blue + ENABLE APIS AND SERVICES button at the top of the dashboard.
  3. In the search box, type Gmail API and press Enter.
  4. Click on the Gmail API card in the search results.
  5. Click the blue Enable button.

4

Configure the OAuth Consent Screen

The OAuth Consent Screen defines how your application identifies itself to Google's authentication system.

Which User Type Should You Choose?

Internal Paid Google Workspace

Choose this if you have a paid Google Workspace domain (e.g., you@company.com). Email access is restricted strictly to users inside your organization.

External Free @gmail.com

Choose this if you use a free personal account ending in @gmail.com or @googlemail.com.

  1. In the left sidebar, click APIs & Services → OAuth consent screen.
  2. Select your User Type (Internal or External) and click Create.
  3. Fill in the essential App Information:
    • App name: e.g., My Website Email Router
    • User support email: Select your Gmail address.
    • Developer contact information: Enter your email address.
  4. Click Save and Continue through the Scopes and Test Users steps without making changes (If you selected External, you can add your own email as a test user if desired).
  5. Navigate back to the OAuth Consent Screen main tab.
  6. Critical Step: If your Publishing Status displays "Testing", click the Publish App button and confirm. Publishing prevents your OAuth authorization tokens from expiring every 7 days!
5

Generate API Credentials

Now generate the OAuth Client ID and Secret key pair required by FluentSMTP.

  1. In the Google Cloud left sidebar, click Credentials.
  2. Click the + CREATE CREDENTIALS button at the top and select OAuth client ID.
  3. In the Application type dropdown, choose Web application.
  4. Scroll down to the Authorized redirect URIs section and click + ADD URI.
  5. Paste the Authorized Redirect URI that you copied from FluentSMTP in Step 1.
  6. Click Create.
Google Pop-Up Credentials Window Keep Secret
Client ID Format Example:
123456789012-abc123def456.apps.googleusercontent.com
Client Secret Format Example:
GOCSPX-abc123XYZ_SecretKeyString

Copy both your Client ID and Client Secret from the pop-up dialogue. You will paste them into WordPress in the next step.

6

Complete Setup & Authenticate in FluentSMTP

Return to your WordPress tab and finalize the connection.

  1. Switch back to your browser tab with FluentSMTP Settings.
  2. Fill out the Sender Settings form fields:
    • From Email: Your exact Gmail or Google Workspace email address.
    • From Name: The sender name recipients will see (e.g., My Store Support).
    • Application Client ID: Paste the Client ID copied from Google.
    • Application Client Secret: Paste the Client Secret copied from Google.
  3. Click Authenticate with Google & Get Access Token.
  4. In the Google authorization pop-up, select the same Gmail/Workspace account used to set up the project.
Bypassing Google's "Unverified App" Prompt

Because you created a custom private Google Cloud application, Google will display a security prompt stating "Google hasn't verified this app". This is 100% normal and expected.

How to proceed:

1. Click the small Advanced link at the bottom left of the prompt screen.

2. Click Go to [Your App Name] (unsafe).

3. Click Continue / Allow to grant FluentSMTP permission to route emails.

Once authorized, Google redirects you back to FluentSMTP with an access token automatically generated. Click Save Connection Settings.

7

Test Email Delivery

Confirm that your Google API connection sends emails properly from your WordPress site.

  1. In the FluentSMTP dashboard, click on the Email Test tab.
  2. Enter an active email address in the Send To field.
  3. Click Send Test Email.
  4. Check the inbox of the target email account. If you receive the confirmation message, your WordPress emails are fully configured and authenticated via Google OAuth 2.0!
Congratulations!

Your site emails are now routed through Google's secure API servers. You can review delivery status anytime under the Email Logs tab in FluentSMTP.
