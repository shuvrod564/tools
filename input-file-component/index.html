File Input Component

A globally reusable file input with drag-and-drop, preview, metadata, and validation. Works for any file type.

Banner Image Upload
Single image file with thumbnail preview. Shows existing image from server.
Drag & drop or browse files
PNG, JPG, WEBP up to 2MB
current-banner.jpg — Existing image
Document Upload
Any file type with icon-based preview instead of thumbnail.
Drag & drop or choose document
PDF, DOC, XLS, CSV, TXT up to 5MB
Gallery Image (Full Preview)
Larger preview area suitable for gallery or hero images.
Drop a high-res image or browse
PNG, JPG, WEBP up to 4MB
How to Use Globally
Add data-file-input to any drop zone. The script handles everything automatically.
<div class="file-drop-zone" data-file-input data-accept="image/*" data-max-size="2" data-preview="thumb"> <input type="file" class="form-control" name="banner_image"> <div class="file-upload-prompt">...</div> <div class="file-preview-card">...</div> </div> // data-accept → MIME types or extensions // data-max-size → max MB (optional) // data-preview → "thumb" | "full" | "icon" // data-label → label for toast messages
